# Шрифты

Интерфейс использует два свободных шрифта (лицензия **SIL Open Font License 1.1**),
загружаемых в рантайме из этой папки (`_load_fonts()` в `Game.gd`):

- **Play** (`Play-Regular.ttf`) — основной текст интерфейса и HUD.
  © 2011 Jonas Hecksher, Playtype / e-types AS. Лицензия: `Play-OFL.txt`.
- **Russo One** (`RussoOne-Regular.ttf`) — заголовки (крупный текст ≥ 26px).
  © 2011–2012 Jovanny Lemonad. Лицензия: `RussoOne-OFL.txt`.

Оба шрифта поддерживают кириллицу и латиницу. Для эмодзи-иконок предметов
задан фоллбэк на системный шрифт (`ThemeDB.fallback_font`).

OFL 1.1 разрешает свободное использование, включая в коммерческих проектах,
при условии сохранения файлов лицензии (они лежат рядом).
