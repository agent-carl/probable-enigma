# GUNFALL — платформер-рогалик (Godot 4)

Локальная игра для ПК на движке **Godot 4.3**. Платформер-рогалик: каждый
забег — новая, процедурно сгенерированная карта; бой через огнестрельное
оружие; улучшения между уровнями; перманентная смерть.

## Как запустить

1. Скачайте **Godot 4.3+** (один исполняемый файл, без установки):
   https://godotengine.org/download
2. Запустите Godot → **Import** → выберите файл `godot/project.godot` из этого
   репозитория → **Import & Edit**.
3. Нажмите **F5** (или кнопку ▶ «Run Project»).

### Собрать в один исполняемый файл (.exe / .app / бинарник)

В Godot: **Project → Export**, добавьте пресет нужной платформы (Windows /
Linux / macOS), скачайте export templates по подсказке движка и нажмите
**Export Project**. Получите самостоятельный файл, который запускается
двойным кликом без установленного Godot.

## Механики

- 🗺️ **Процедурная генерация**: рельеф, ямы с шипами, односторонние платформы,
  враги и лут генерируются из сида. Один и тот же сид даёт одну и ту же карту.
- 🔫 **4 вида оружия**: пистолет (бесконечные патроны), ПП «Оса» (автоогонь),
  дробовик (6 дробин веером), винтовка (мощный точный выстрел). Прицеливание
  мышью, отдача, криты, ограниченный боезапас.
- 👾 **4 типа врагов**: патрульные, турели-стрелки, летуны и бронированные
  «танки» с тройным выстрелом. ИИ реагирует только при прямой видимости.
- 🃏 **Рогалик-прогрессия**: после каждого уровня — выбор 1 из 3 случайных
  улучшений (двойной прыжок, вампиризм, броня, криты и т.д.). Сложность
  растёт бесконечно, смерть перманентна.
- 🎛️ **Отзывчивое управление**: coyote time, jump buffering, переменная высота
  прыжка, спрыгивание с платформ.
- ✨ Параллакс-фон, 5 визуальных тем, частицы, тряска экрана, процедурный звук
  (синтез на лету, без аудиофайлов), рекорд в `user://`.

## Управление

| Действие | Клавиши |
|---|---|
| Бег | A / D или ← / → |
| Прыжок | W / ↑ / Пробел |
| Спрыгнуть с платформы | S + прыжок |
| Прицел / огонь | Мышь / ЛКМ |
| Смена оружия | 1–4 или колесо мыши |
| Пауза | Esc или P |
| Звук вкл/выкл | M |

## Структура проекта

- `project.godot` — конфигурация проекта (главная сцена, окно 960×540, физика 60 Гц).
- `Main.tscn` — главная сцена (один `Node2D` со скриптом).
- `Game.gd` — вся игра: генерация, физика, ИИ, оружие, отрисовка (`_draw`), звук.
- `Test.gd` — headless-автотесты генерации и симуляции геймплея.
- `icon.svg` — иконка проекта.

## Автотесты

Логика покрыта headless-тестами (генерация 480 карт на проходимость и
детерминизм + симуляция геймплея на тысячи кадров с проверкой инвариантов):

```bash
godot --headless --path godot --script res://Test.gd
```
