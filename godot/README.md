# GUNFALL — платформер-рогалик (Godot 4)

Локальная игра для ПК на движке **Godot 4.6** (последняя стабильная версия).
Платформер-рогалик: каждый забег — новая, процедурно сгенерированная карта;
бой через огнестрельное оружие; улучшения между уровнями; перманентная смерть.

> Проект использует только стабильный API Godot 4.x, поэтому открывается и в
> Godot 4.3–4.5, но рекомендуется актуальная 4.6.

## Как запустить

1. Скачайте **Godot 4.6** (один исполняемый файл, без установки):
   https://godotengine.org/download
2. Запустите Godot → **Import** → выберите файл `godot/project.godot` из этого
   репозитория → **Import & Edit**.
3. Нажмите **F5** (или кнопку ▶ «Run Project»).

### Релизы с готовыми билдами (рекомендуется)

Самый простой способ — одной кнопкой, без работы с тегами:

1. На GitHub: **Actions → «GUNFALL build» → Run workflow**.
2. В поле версии введите `v0.1.0` и запустите.
3. Workflow соберёт Windows/Linux/Web, создаст **тег и релиз** этой версии и
   прикрепит к нему `gunfall-windows.zip` (`.exe`), `gunfall-linux.zip` и
   `gunfall-web.zip` (играть в браузере) + авто-заметки об изменениях.

Альтернатива: **Releases → Draft a new release**, создать тег `vX.Y.Z` и нажать
**Publish release** — тот же workflow прикрепит к нему билды.

Скачиваете нужный архив со страницы релиза — игра запускается двойным кликом
без установленного Godot. Каждая версия `vX.Y.Z` = отдельный релиз с билдами.

### Скачать билды из прогона CI (без релиза)

Можно и без релиза: **Actions → «GUNFALL build» → Run workflow** — артефакты
`gunfall-windows` / `gunfall-linux` / `gunfall-web` появятся на странице прогона.

### Играть в браузере (GitHub Pages, опционально)

Workflow **GUNFALL web (Pages)** публикует Web-версию на GitHub Pages.
Сначала включите **Settings → Pages → Source = «GitHub Actions»** (для
приватного репозитория нужен подходящий тариф), затем запустите его вручную
(**Actions → «GUNFALL web (Pages)» → Run workflow**).

### Собрать локально

В проекте уже есть пресеты экспорта (`export_presets.cfg`). В Godot:
**Project → Export**, скачайте export templates по подсказке движка и нажмите
**Export Project**. Либо из консоли:

```bash
godot --headless --path godot --export-release "Windows" build/gunfall.exe
```

## Механики

- 🗺️ **Процедурная генерация**: рельеф, ямы с шипами, односторонние платформы,
  враги и лут генерируются из сида. Один и тот же сид даёт одну и ту же карту.
- 🔫 **7 видов оружия**: пистолет (∞ патронов), ПП «Оса» (автоогонь), дробовик
  (6 дробин веером), винтовка (точный выстрел), **гранатомёт** (дуговой снаряд
  со взрывом по площади), **рельса** (луч, пробивающий несколько врагов) и
  **огнемёт** (конус огня ближнего боя, поджигает врагов). Прицеливание мышью,
  отдача, криты, ограниченный боезапас.
- 👾 **9 типов врагов**: патрульные, турели-стрелки, летуны, бронированные
  «танки» с тройным выстрелом, **камикадзе** (несутся к игроку и взрываются),
  **снайперы** (наводят луч-прицел и бьют мощным выстрелом — можно увернуться),
  **делящиеся** (при гибели распадаются на два быстрых осколка), **тараны**
  (разгоняются и совершают рывок — нужно уйти с линии, после удара о стену
  оглушены) и **лекари** (парят, держатся подальше и лечат соседних врагов —
  приоритетная цель). ИИ реагирует только при прямой видимости.
- 💥 **Взрывы по площади** — единая система для гранат и камикадзе: урон по
  радиусу, частицы и тряска экрана.
- 📦 **Разрушаемые ящики** — твёрдые тайлы, которые служат укрытием от
  вражеского огня (блокируют пули и линию видимости) и ломаются вашими
  выстрелами и взрывами, роняя лут.
- 🛗 **Движущиеся платформы и лифты** — горизонтальные и вертикальные
  односторонние платформы, которые переносят игрока (приземляешься сверху).
- 🪚 **Пилы-ловушки** — вращающиеся лезвия, что ездят по открытым коридорам
  и ранят при касании; их нужно облетать рывком и прыжками.
- 🌋 **Лава/кислота** — светящиеся опасные ямы (свой цвет и оттенок света у
  каждой темы: оранжевая лава, зелёная кислота, синяя плазма). Наносят урон и
  выталкивают наверх, бурлят и освещают округу. Шанс лавовой ямы растёт с
  уровнем; их перепрыгивают.
- 👑 **Боссы каждый 5-й уровень** трёх видов, чередующихся по кругу: наземный
  **«Страж Земли»** (преследует, прыгает, веерные залпы), летающий **«Небесный
  Страж»** (парит, пикирует, радиальные залпы) и **«Призыватель»** (парит,
  призывает миньонов и стреляет). У каждого свои паттерны и именная полоса
  здоровья; портал открывается только после победы.
- ⭐ **Элитные враги** с модификаторами (бронированный / быстрый): прочнее,
  дают больше очков, светятся аурой и роняют дополнительный лут.
- 🧭 **Индикаторы урона** — вспышки по краям экрана показывают, откуда прилетело.
- 🔥❄ **Статус-эффекты**: горение (урон по времени) и заморозка (замедление).
  Взрывы поджигают; улучшения «Зажигательные» и «Крио-патроны» дают пулям
  шанс наложить статус.
- 💥 **Ультимейт «Перегрузка»** (Q): заряжается по мере нанесённого урона; по
  готовности — ударная волна, которая бьёт врагов вокруг, отбрасывает их,
  развеивает вражеские пули и даёт кадры неуязвимости.
- 💨 **Рывок** (Shift / ПКМ): быстрый рывок с кадрами неуязвимости, следами и
  кулдауном — уход от пуль и пробросы над пропастями.
- 🛡️ **Щит**: подбираемый энергощит поглощает урон раньше здоровья; виден
  кольцом вокруг героя и отдельной полосой на HUD.
- 🔥 **Серия убийств**: быстрые убийства подряд наращивают множитель очков
  (до x4), который виден на HUD.
- 🗺️ **Мини-карта**: силуэт уровня, портал, враги (с цветами по типам) и
  игрок в углу экрана.
- 📊 **Статистика забега**: на экране смерти — точность стрельбы, лучшая серия,
  нанесённый урон, время и рекорд. Подсветка нового рекорда.
- 🔊 **Громкость**: регулируется клавишами − / + (и видна в меню/паузе),
  сохраняется между запусками.
- 🃏 **Рогалик-прогрессия**: после каждого уровня — выбор 1 из 3 из **14**
  улучшений. Помимо базовых (HP, урон, скорострельность, двойной прыжок,
  вампиризм, броня, криты, прыжок) есть синергии с новыми системами:
  энергощит с регенерацией, ускоренный рывок, «Сапёр» (мощнее взрывы),
  магнит для предметов и «Берсерк» (урон растёт с серией убийств). Смерть
  перманентна, сложность растёт бесконечно.
- 🔮 **Реликвии (10 шт.)**: мощные пассивки с уникальными триггерами, а не
  просто прибавки к статам — стекло-пушка (+урон/−HP), вампиризм на убийство,
  детонация трупов, цепь молний, касание Мидаса, адреналин при низком HP,
  шипы-отдача, второе дыхание (переживает смертельный удар), сверхзаряд ульты
  и морозная аура. Выпадают за победу над боссом и продаются в магазине;
  отображаются иконками на HUD. Складываются в билды и синергируют.
- 🪙 **Монеты и магазин**: с врагов и ящиков падают монеты; перед каждым
  3-м уровнем открывается магазин, где их можно потратить на аптечку,
  боезапас, щит, новый ствол, случайное улучшение или **реликвию**.
- 🏆 **Достижения** (8 шт.): первая кровь, серия x10, победа над боссом,
  арсенал, глубина, снайпер, рекорд очков, выживание — с всплывающими
  уведомлениями и сохранением прогресса.
- 🎛️ **Отзывчивое управление**: coyote time, jump buffering, переменная высота
  прыжка, спрыгивание с платформ, look-ahead камеры по прицелу.
- 🧭 **Указатель за краем экрана** на портал или босса, когда цель не видна.
- 🌦️ **Атмосфера по теме**: у каждой из 5 тем своя погода — парящие споры
  (пещеры), летящие угольки (руины), снег (шахты), пузыри (топи) и песчаная
  позёмка (форт).
- 🎵 **Процедурная фоновая музыка**: зацикленная тема (бас + арпеджио по
  пентатонике) генерируется на лету для каждой из 5 локаций, с отдельным,
  более быстрым вариантом для боссов. Без аудиофайлов.
- ✨ Параллакс-фон (кэш-текстура неба), 5 визуальных тем, частицы, тряска
  экрана, hit-stop на убийстве босса, процедурные звуковые эффекты (синтез на
  лету, без аудиофайлов). Рекорд и громкость хранятся в `user://gunfall.cfg`.
- 🧱 Процедурные пиксель-текстуры земли (дизеринг + бевел/AO), травянистой
  кромки, платформ-досок и деревянных ящиков, под цвет каждой темы;
  металлические двухтоновые шипы; тёмные контуры и верхний блик у героя и
  врагов; параллакс-холмы с вертикальным градиентом для глубины.
- 🎇 Искры при попадании пуль в стены/ящики (разлетаются от поверхности) и
  вращающиеся блестящие монеты.
- 💡 **Динамическое освещение**: атмосферное затемнение мира по тону локации и
  светящиеся пятна-источники — аура игрока (ярче в рывке), пули, дульные
  вспышки, взрывы (растут с ударной волной), пульсирующий портал, предметы и
  мерцающий огонь на горящих врагах. Свет ложится на мир, не затрагивая HUD.
- ✨ **HDR-свечение (bloom)**: яркие источники — лава, вспышки выстрелов,
  трассеры/криты, портал, ультимейт — «цветут» через настоящий движковый glow
  (`WorldEnvironment` + HDR-2D, рендер Forward+). Тонко настроено, чтобы не
  засвечивать сцену; отключается в паузе (опция сохраняется).
- 🌒 **Динамические тени**: фонарь игрока строит полигон видимости (лучи
  упираются в рёбра стен и ящиков) и рисуется как мягкое пятно с резкими
  краями теней — свет не проходит сквозь препятствия, тени двигаются вместе с
  героем. Реализовано без триангуляции, через веер треугольников.
- 🎨 **Цветокоррекция и тонмаппинг**: AgX-тонмаппинг (мягкий «киношный» спад
  ярких пятен — bloom не выжигает) + контраст/насыщенность через
  `WorldEnvironment`. Сглаживание 2D (MSAA) для чистых краёв лучей света.
- 🌬️ **Объёмные лучи (god rays)** от портала — вращающиеся аддитивные HDR-шафты;
  **пылинки**, дрейфующие в воздухе и ярче вспыхивающие рядом со светом.
- 🌀 **Экранный пост-эффект** (полноэкранный шейдер, читающий экран): тепловое
  **марево над лавой**, **рефракция-рябь** от взрывов и ударной волны ультимейта,
  **хроматическая аберрация** при получении урона.
- 🟢 **Squash & stretch**: герой вытягивается в прыжке и приседает при
  приземлении (тем сильнее, чем жёстче падение).
- ⏱️ **Слоу-мо при гибели босса** (`Engine.time_scale`) — эффектный замедленный
  момент с авто-восстановлением по реальному времени.
- 🎬 **Ирис-переход** между уровнями — круглое «окно» раскрывается на игроке.
- 🎞️ **Леттербокс на боссовых уровнях** во время интро (кинематографичная подача).
- ❤️‍🔥 **Пульс при низком HP** — красная виньетка пульсирует тем сильнее, чем
  меньше здоровья.
- 🏔️ **Третий дальний слой параллакса** — больше глубины фона.
- 🌌 **Дрейфующие полосы-сияние** в небе (мягкие шторы света по теме).
- 🌋 **Текущая лава** — бегущий по поверхности яркий блик (эффект потока).
- 📺 **Опциональный CRT-фильтр** (скан-лайны, лёгкая бочка-дисторсия, виньетка) —
  движковый экранный шейдер, включается в паузе.
- 🖥️ **Полноэкранный режим** (F11 или в паузе), сохраняется между запусками.
- 🎞️ **Цветокоррекция по локациям** (LUT-грейдинг в шейдере): у каждого биома
  свой кинематографичный тон — тёплые руины, ледяные шахты, ядовитые топи и т.д.
- 🪞 **Отражение игрока на лаве** — перевёрнутое дрожащее отражение в цвете лавы,
  когда герой над поверхностью.
- 🎆 **Движковые частицы** (`CPUParticles2D`): аддитивные светящиеся искры на
  взрывах и при гибели босса, выровненные с миром, с затуханием и гравитацией.
- 🖼️ **HUD на отдельном `CanvasLayer`** поверх пост-эффектов: интерфейс остаётся
  чётким и не искажается маревом/аберрацией/CRT/грейдингом (мир обрабатывается,
  UI — нет).
- 🔮 **Размытие мира на паузе/оверлеях** (depth-of-field фокус): мир мягко
  размывается за меню, а интерфейс остаётся чётким.
- 🎞️ **Плёночное зерно** — тонкая анимированная текстура поверх кадра.
- 🎯 **Хит-маркеры и реактивный прицел**: крестик-вспышка при попадании, прицел
  раскрывается при выстреле и красится в цвет оружия.
- 💥 **Гибы и щепки**: светящиеся частицы разлетаются при гибели врага и
  разрушении ящика.
- 🌗 **Тени от портала** — портал тоже отбрасывает динамические тенями (полигон
  видимости), не только фонарь игрока.
- 🏞️ **Передний слой параллакса** — тёмные силуэты у нижней кромки скроллятся
  быстрее мира (ощущение глубины).
- 💨 **Линии скорости при рывке** — штрихи у краёв экрана в сторону рывка.
- ❤️ **Плавная просадка HP** — бледно-красная «призрак»-полоса показывает недавний
  урон и плавно догоняет здоровье (как в файтингах).
- 🔥 **Поп серии убийств** — текст серии вспыхивает и увеличивается при убийстве,
  вспышка экрана на майлстоунах (x5/x10/…).
- 🔫 **Анимация смены оружия** — выбранный слот вспыхивает и увеличивается.
- ✨ **Сияние подбора** — вспышка частиц и кольцо при подборе предмета.
- 🩸 **Трещины на экране** при критическом HP (<22%) — «разбитое стекло» от краёв,
  ярче по мере приближения к смерти.
- 🌀 **Радиальный блюр на ультимейте** — кадр смазывается к центру при «Перегрузке».
- 💥 **Кольцо-поп врага** — при попадании от врага расходится короткое кольцо.
- 🔩 **Гильзы** — вылетают из оружия при выстреле и падают.
- 💡 Визуальный лоск: мягкое свечение пуль/предметов/портала/игрока, контактные
  тени под врагами и героем, виньетка по краям экрана, блик и анимация бега,
  вспышки выстрела, расходящиеся ударные кольца от взрывов, полноэкранная
  вспышка на ульте/смерти босса и плавное появление уровня из затемнения.

## Управление

| Действие | Клавиши |
|---|---|
| Бег | A / D или ← / → |
| Прыжок | W / ↑ / Пробел |
| Спрыгнуть с платформы | S + прыжок |
| Прицел / огонь | Мышь / ЛКМ |
| Рывок | Shift или ПКМ |
| Ультимейт «Перегрузка» | Q |
| Смена оружия | 1–7 или колесо мыши |
| Громкость | − / + |
| Пауза | Esc или P |
| Звук вкл/выкл | M |

Поддерживается **геймпад**: левый стик/крестовина — движение, правый стик —
прицел, A — прыжок, правый триггер/RB — огонь, левый триггер/B — рывок,
Y — ультимейт, LB — смена оружия. На паузе можно настроить **тряску экрана**,
**свечение (bloom)**, **CRT-фильтр** и **полноэкранный режим** (F11) — все
опции сохраняются.

## Структура проекта

- `project.godot` — конфигурация проекта (главная сцена, окно 960×540, физика 60 Гц).
- `Main.tscn` — главная сцена (один `Node2D` со скриптом).
- `Game.gd` — игра: генерация, физика, ИИ, оружие, отрисовка (`_draw`), звук.
- `Synth.gd` — процедурный аудио-DSP (тоны, шум, музыка) — статические функции.
- `Test.gd` — headless-автотесты генерации и симуляции геймплея.
- `export_presets.cfg` — пресеты экспорта (Windows / Linux / Web).
- `icon.svg` — иконка проекта.

## Автотесты

Логика покрыта headless-тестами (генерация 480 карт на проходимость и
детерминизм + симуляция геймплея на тысячи кадров с проверкой инвариантов):

```bash
godot --headless --path godot --script res://Test.gd
```
