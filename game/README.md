# GUNFALL — платформер-рогалик 🔫

Браузерный платформер-рогалик на чистом HTML/CSS/JavaScript (Canvas), без
зависимостей и сборки. Каждый забег — новая, процедурно сгенерированная карта.

## Механики

- 🗺️ **Процедурная генерация**: рельеф, ямы с шипами, односторонние платформы,
  враги и лут генерируются из сида. Можно ввести свой сид и сыграть ту же карту.
- 🔫 **4 вида огнестрельного оружия**: пистолет (бесконечные патроны),
  ПП «Оса» (автоматический), дробовик (6 дробин), винтовка (мощный одиночный).
  Прицеливание мышью, отдача, криты, ограниченный боезапас.
- 👾 **4 типа врагов**: патрульные, турели-стрелки, летуны и бронированные
  «танки» с тройным выстрелом. Враги видят игрока только по прямой видимости.
- 🃏 **Рогалик-прогрессия**: после каждого уровня — выбор 1 из 3 случайных
  улучшений (двойной прыжок, вампиризм, броня, криты и т.д.). Смерть
  перманентна, сложность растёт бесконечно.
- 🎛️ **Отзывчивое управление**: coyote time, jump buffering, переменная высота
  прыжка, спрыгивание с платформ.
- ✨ Параллакс-фон, 5 визуальных тем, частицы, тряска экрана, звук на WebAudio
  (без аудиофайлов), рекорд в localStorage.

## Управление

| Действие | Клавиши |
|---|---|
| Бег | A / D или ← / → |
| Прыжок | W / ↑ / Пробел |
| Спрыгнуть с платформы | S + прыжок |
| Прицел / огонь | Мышь / ЛКМ |
| Смена оружия | 1–4 или колесо мыши |
| Пауза | Esc или P |
| Звук вкл/выкл | M |

## Запуск

Статические файлы, сборка не нужна:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/game/
```
