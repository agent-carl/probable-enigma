# GUNFALL — платформер-рогалик 🔫

Локальная игра для ПК на движке **Godot 4.6**. Платформер-рогалик: каждый
забег — новая, процедурно сгенерированная карта; бой через огнестрельное
оружие; улучшения между уровнями; перманентная смерть.

Сам проект находится в папке **[`godot/`](godot/)** — там же подробный README
с описанием механик, управления и инструкцией по запуску.

## Быстрый старт

1. Скачайте **Godot 4.6** (один исполняемый файл, без установки):
   https://godotengine.org/download
2. В Godot нажмите **Import** и выберите `godot/project.godot`.
3. Нажмите **F5** (▶ Run Project).

Можно также собрать самостоятельный `.exe`/бинарник через **Project → Export**.

## Кратко о механиках

- 🗺️ Процедурная генерация уровней из сида (рельеф, ямы с шипами, платформы, лут).
- 🔫 7 видов оружия: пистолет, ПП, дробовик, винтовка, гранатомёт (взрыв по
  площади), рельса (пробивает насквозь) и огнемёт (конус огня, поджигает) —
  прицел мышью, отдача, криты.
- 👾 7 типов врагов (камикадзе, снайперы с лучом-прицелом, делящиеся и др.) + ⭐ элитные модификации + 👑 три вида боссов (наземный, летающий, призыватель), чередующихся каждый 5-й уровень.
- 📦 Разрушаемые ящики-укрытия: блокируют огонь, ломаются выстрелами/взрывами, роняют лут.
- 🛗 Движущиеся платформы и лифты, переносящие игрока.
- 🪚 Пилы-ловушки, ездящие по коридорам.
- 🌋 Светящиеся лавовые/кислотные ямы (урон + свет), свои у каждой темы.
- 💨 Рывок с i-кадрами, 🛡️ щит и 🔥 множитель очков за серию убийств.
- 🔥❄ Статус-эффекты (горение/заморозка) и 💥 ультимейт «Перегрузка» (заряд от урона).
- 🎮 Поддержка геймпада и опция отключения тряски экрана (сохраняется).
- 🗺️ Мини-карта, 📊 статистика забега (точность/урон/время) и 🔊 настройка громкости.
- 🃏 Рогалик-прогрессия: 14 улучшений (синергии с щитом/рывком/взрывами/комбо), перманентная смерть.
- 🪙 Монеты и магазин между уровнями (аптечки, патроны, щит, оружие, прокачка).
- 🏆 8 достижений с уведомлениями и сохранением.
- 💡 Динамическое освещение: атмосферное затемнение мира + светящиеся пятна от игрока, пуль, вспышек, взрывов, портала, предметов и огня.
- ✨ Параллакс-фон, 5 тем со своей погодой (споры/угольки/снег/пузыри/песок), частицы, тряска экрана, процедурный звук.
- 🎵 Процедурная фоновая музыка по локациям (своя тема + боссовый вариант).

## Автотесты

Логика покрыта headless-тестами Godot (генерация карт + симуляция геймплея):

```bash
godot --headless --path godot --script res://Test.gd
```

Подробности — в [`godot/README.md`](godot/README.md).
