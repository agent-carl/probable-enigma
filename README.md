# SubTrack — трекер подписок 💳

> 🎮 В репозитории также живёт **[GUNFALL](game/)** — платформер-рогалик с
> процедурной генерацией уровней и огнестрельным оружием. Подробности в
> [game/README.md](game/README.md).

Простое приложение для повседневной жизни: учитывает все ваши подписки
(Яндекс Плюс, Netflix, iCloud, ChatGPT…) и показывает, **сколько вы на самом
деле тратите каждый месяц** и **когда следующее списание**.

Среднестатистический человек платит за 5–8 подписок и забывает минимум об
одной — SubTrack решает именно эту проблему.

## Возможности

- ➕ Добавление подписок: цена, валюта (₽/$ /€/₸), период (неделя/месяц/квартал/год), дата списания, категория
- 📊 Сводка: расходы в месяц и в год, число подписок, ближайшее списание
- ⏰ Подсветка подписок, которые спишутся сегодня или в ближайшие 3 дня
- 🔍 Поиск, фильтр по категориям, сортировка (по дате/цене/названию)
- 💾 Данные хранятся локально (localStorage) — никакой регистрации и серверов
- 📤 Экспорт и импорт в JSON (резервная копия, перенос между устройствами)
- 📱 PWA: ставится на телефон как приложение и работает офлайн
- 🇷🇺 Автоподсказки популярных сервисов при вводе названия

## Запуск

Это статический сайт без зависимостей и сборки:

```bash
# любой статический сервер, например:
python3 -m http.server 8000
# открыть http://localhost:8000
```

Деплой — бесплатно на GitHub Pages, Netlify или Vercel: просто опубликуйте
содержимое репозитория.
