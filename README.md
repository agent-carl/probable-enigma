# GUNFALL — платформер-рогалик 🔫

Локальная игра для ПК на движке **Godot 4.6**. Платформер-рогалик: каждый
забег — новая, процедурно сгенерированная карта; бой через огнестрельное
оружие; улучшения между уровнями; перманентная смерть.

Сам проект находится в папке **[`godot/`](godot/)** — там же подробный README
с описанием механик, управления и инструкцией по запуску.

## Быстрый старт

1. Скачайте **Godot 4.6** (один исполняемый файл, без установки):
   https://godotengine.org/download
2. В Godot нажмите **Import** и выберите `godot/project.godot`.
3. Нажмите **F5** (▶ Run Project).

Можно также собрать самостоятельный `.exe`/бинарник через **Project → Export**.

## Кратко о механиках

- 🗺️ Процедурная генерация уровней из сида (рельеф, ямы с шипами, платформы, лут).
- 🔫 4 вида оружия: пистолет, ПП, дробовик, винтовка — прицел мышью, отдача, криты.
- 👾 4 типа врагов с ИИ по прямой видимости + 👑 боссы каждый 5-й уровень.
- 💨 Рывок с i-кадрами и 🔥 множитель очков за серию убийств.
- 🃏 Рогалик-прогрессия: выбор улучшений между уровнями, перманентная смерть.
- ✨ Параллакс-фон, 5 тем, частицы, тряска экрана, процедурный звук.

## Автотесты

Логика покрыта headless-тестами Godot (генерация карт + симуляция геймплея):

```bash
godot --headless --path godot --script res://Test.gd
```

Подробности — в [`godot/README.md`](godot/README.md).
