# SubTrack — трекер подписок 💳

Простое приложение для повседневной жизни: учитывает все ваши подписки
(Яндекс Плюс, Netflix, iCloud, ChatGPT…) и показывает, **сколько вы на самом
деле тратите каждый месяц** и **когда следующее списание**.

Среднестатистический человек платит за 5–8 подписок и забывает минимум об
одной — SubTrack решает именно эту проблему.

## Возможности

- ➕ Добавление подписок: цена, валюта (₽/$ /€/₸), период (неделя/месяц/квартал/год), дата списания, категория
- 📊 Сводка: расходы в месяц и в год, число подписок, ближайшее списание
- ⏰ Подсветка подписок, которые спишутся сегодня или в ближайшие 3 дня
- 🔍 Поиск, фильтр по категориям, сортировка (по дате/цене/названию)
- 💾 Данные хранятся локально (localStorage) — никакой регистрации и серверов
- 📤 Экспорт и импорт в JSON (резервная копия, перенос между устройствами)
- 📱 PWA: ставится на телефон как приложение и работает офлайн
- 🇷🇺 Автоподсказки популярных сервисов при вводе названия

## Запуск

Это статический сайт без зависимостей и сборки:

```bash
# любой статический сервер, например:
python3 -m http.server 8000
# открыть http://localhost:8000
```

Деплой — бесплатно на GitHub Pages, Netlify или Vercel: просто опубликуйте
содержимое репозитория.

## Технологии

Чистые HTML / CSS / JavaScript. Ни одной зависимости, ни одного шага сборки —
легко поддерживать и дёшево хостить (фактически бесплатно).

## 💰 Как это монетизировать

Модель — **freemium**. Базовая версия бесплатна навсегда (это канал
привлечения), платят за удобство:

| Бесплатно | Pro (~149 ₽/мес или 990 ₽/год) |
|---|---|
| До 7 подписок | Без ограничений |
| Локальное хранение | Облачная синхронизация между устройствами |
| — | Push/email-напоминания «спишется завтра» |
| — | Статистика и графики расходов по месяцам |
| — | Семейный доступ (общие подписки) |
| — | Автоконвертация валют по курсу |

Дорожная карта монетизации:

1. **MVP (готов)** — собрать аудиторию: GitHub Pages + посты в соцсетях,
   Product Hunt, vc.ru. Продукт локальный, приватный — это аргумент.
2. **Телеграм-бот напоминаний** — первая платная фича с минимальными
   затратами (бот дешевле пушей и привычнее аудитории РФ).
3. **Аккаунты + синхронизация** — лёгкий бэкенд (Supabase/Firebase),
   подписка через ЮKassa / CloudPayments / Telegram Stars.
4. **B2B-партнёрка** — кэшбэк-интеграции и рекомендации «дешёвых» тарифов
   (партнёрские ссылки на сервисы — доход с каждой подписки по реферальной
   программе).

Юнит-экономика привлекательна: хостинг статики бесплатный, значит почти
каждый платящий пользователь — чистая прибыль.
